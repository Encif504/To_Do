# React Tailwind Portfolio

A portfolio scaffold built with React, Vite, Tailwind CSS, and optimized for Vercel deployment.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start local development:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Deploy to Vercel

1. Sign in to Vercel and create a new project.
2. Link the repository or import the project folder.
3. Use the default settings; Vercel will detect Vite automatically.
4. Set the build command to `npm run build` and the output directory to `dist`.

## Customize

- Update `src/App.jsx` with your name, story, and projects.
- Replace `mailto:hello@example.com` in the contact section.
- Add more sections, portfolio cards, and links as needed.
